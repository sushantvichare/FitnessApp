## Fitness App

FitAI is a full-stack, AI-powered fitness application built with a scalable microservices architecture. Get personalized workout plans, real-time form analysis, progress tracking, and nutrition recommendations powered by Google's Gemini API.

🚀 Features
AI Workout Generator: Custom plans based on goals, fitness level, and equipment using Gemini AI.

Real-time Form Feedback: Computer vision-powered pose detection (coming soon).

Progress Analytics: Track metrics with interactive dashboards.

Social Challenges: Compete with friends and global leaderboards.

Nutrition Integration: AI-suggested meal plans synced with workouts.

🛠 Tech Stack
Frontend: React
Backend: Spring Framework, Spring Cloud Netflix Eureka, RabbitMQ, Keycloak, PostgreSQL, MongoDB
AI Service: Google Gemini API

Microservices architecture ensures scalability, fault tolerance, and independent deployment.
